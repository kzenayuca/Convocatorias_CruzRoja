# Recorrido manual

1. Ejecute `docker compose up -d --build` y abra `http://localhost:8088`.
2. Use solo teclado: active “Saltar al contenido”, recorra navegación y compruebe foco.
3. A 360 px, abra Convocatorias y confirme que no hay desplazamiento horizontal.
4. Revise cupos, Inscripciones, Mis horas, Justificaciones y Avisos.
5. En `/ui`, revise controles normales, activos, estados y carga.
6. Pruebe la API en orden: login → convocatoria → inscripción → asistencia → justificación → notificación.
