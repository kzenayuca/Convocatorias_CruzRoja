# Sistema de diseño Soft UI

Superficie `#E6EAF0`, sombras claras/oscuras, radios de 14–20 px y rojo institucional. Todos los valores están en `tokens.css`. Los controles tienen borde de 1,5 px, objetivo mínimo de 44 px, foco de 3 px, estado presionado hundido y texto además del color. Se respeta `prefers-reduced-motion` y 360 px.
